# Support

AuthKit is community-maintained on a best-effort basis. There is no SLA, guaranteed response time, paid support promise, or guarantee that every configuration will be supported.

- Use GitHub issues for reproducible public bugs and documentation problems.
- Use discussions or an issue for usage questions that contain no secrets or personal data.
- Use the private process in `SECURITY.md` for vulnerabilities.
- Consult `docs/reference/SUPPORT_MATRIX.md` before filing a production-path issue.

Support applies only to the latest `0.1.x` release and its documented golden path once v0.1.0 is released. Preview, experimental, unsupported, forked, and locally modified deployments may receive guidance but have no production-support commitment. Operators remain responsible for their infrastructure and incident response.
